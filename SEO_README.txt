ВАЖНО ПОСЛЕ ПУБЛИКАЦИИ
1. Загрузите ВСЕ файлы папки в корень GitHub Pages репозитория konsalting.
2. Проверьте доступность адресов /konsalting/sitemap.xml и /konsalting/robots.txt.
3. Учтите: для GitHub Pages проектного сайта /robots.txt у корня github.io принадлежит самому домену. Файл /konsalting/robots.txt не является корневым robots.txt и может игнорироваться поисковиками. Поэтому индексированию прежде всего помогают sitemap.xml, внутренние ссылки, Search Console и Яндекс Вебмастер.
4. Подключение Google Search Console/Яндекс Вебмастер требует подтверждения права доступа и не выполнено. В Search Console для префикса URL https://vitaliyrotan.github.io/konsalting/ можно подтверждать право HTML-файлом; DNS-подтверждение чужого домена github.io недоступно. В Яндекс Вебмастере уточняйте доступные методы подтверждения URL-префикса; если инструмент требует контроль всего домена, потребуется свой домен.
5. Проверьте URL через Google Rich Results Test, Search Console и Telegram (у Telegram иногда кэшируется старый превью).
6. Яндекс Метрика и её цели НЕ подключались: нужен ID счётчика и согласованная политика обработки данных.
7. Индексация и отображение сниппетов не гарантируются наличием метатегов.
